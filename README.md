# CivicRank AI

### AI-Powered Public Infrastructure Monitoring & Prioritization

> **Don't just detect the problem. Know what needs action first.**

CivicRank AI is a web-based prototype designed to help identify and prioritize public infrastructure issues using image evidence, AI-assisted analysis, location information, and a maintenance workflow.

Instead of simply detecting an issue, CivicRank AI focuses on the complete process:

**Detect → Validate Evidence → Explain Risk → Prioritize → Assign → Verify → Resolve**

---

## 🚨 Problem

Public infrastructure problems such as potholes, damaged roads, broken sidewalks, and other civic issues are often reported late or remain unnoticed.

This can lead to:

- Safety risks for citizens
- Delayed maintenance
- Inefficient use of maintenance resources
- Difficulty in deciding which issue needs attention first

CivicRank AI aims to make this process more structured and action-oriented.

---

## 💡 Solution

CivicRank AI analyzes uploaded visual evidence and combines it with:

- Issue classification
- AI confidence
- Evidence quality
- Location information
- Severity
- Recurring reports
- Public impact

It then generates a **priority score** so that higher-risk issues can be handled first.

The system also includes a closed-loop maintenance workflow where a reported issue can be assigned to a maintenance team and later verified using completion evidence.

---

## ✨ Key Features

### 🤖 AI-Assisted Detection

Analyzes uploaded images and identifies the reported infrastructure issue.

### 📊 Confidence & Evidence Analysis

Shows AI confidence and evaluates whether the submitted evidence is strong, moderate, or weak.

### 🚦 Priority Scoring

Generates an action priority score based on factors such as:

- Issue severity
- Safety risk
- Evidence quality
- Location availability
- Recurring reports

### 📍 Location Intelligence

Users can manually enter a location or use browser-based location access to associate the issue with a location.

### 🗺️ Monitoring Dashboard

Provides an overview of reported issues with:

- Total reports
- Critical reports
- Recurring issues
- Average priority
- Issue map
- Report filtering

### 👷 Maintenance Workflow

Reports can move through:

**Reported → Assigned → In Progress → Resolved**

### 📸 Repair Verification

The system compares the original evidence with the submitted completion evidence before marking a report as resolved.

### 🌙 Dark / Light Mode

Responsive interface with both dark and light themes.

### 📱 Responsive Design

Designed to work across desktop and mobile screen sizes.
